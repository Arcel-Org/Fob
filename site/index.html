Everything in one encrypted file

A password manager, TOTP generator & key store

One vault.fob on your USB holds every kind of secret you need — all locked by a single passphrase.

🔑

Passwords

Store, search, generate and auto-copy credentials. Built-in generator with configurable length and character sets.

⏱️

TOTP two-factor

Live 6-digit codes with countdown for any RFC 6238 service. Add entries by pasting a secret or a setup URI.

🔐

SSH keys

Store private keys (Ed25519, RSA, ECDSA) with their passphrases, fingerprints, and import from your machine.

📝

Secure notes

Encrypted free-text entries for recovery codes, PINs, or anything else you want locked away.

🛡️

Plausible deniability

A decoy passphrase opens a realistic fake vault under coercion; a duress passphrase silently destroys the file.

💾

No install on the machine

Plug in the USB and open index.html. Nothing is installed, nothing is stored on the host computer.

Simple by design

Three steps from USB to unlocked

1

Install Fob once

Run the installer to get the fob command — used only for installing/updating and USB operations.

2

Format a USB drive

fob format /dev/sdX erases the stick and creates a v4 Argon2id vault, then writes the browser vault UI to it.

3

Open it in a browser

Open index.html on the USB in any browser, enter your passphrase, and you're in. Unplug to lock.

Security first

Built on modern, audited cryptography

One Rust implementation runs in the CLI and (compiled to WASM) in the browser — no hand-written web crypto, no two code paths to diverge.

Key derivation
Argon2id · 64 MiB
Memory-hard KDF, 3 passes / 4 lanes. Optional max-security profile at 128 MiB / 4 passes / 8 lanes.
Encryption
AES-256-GCM
Authenticated encryption, with per-slot keys separated via HKDF-SHA256.
Post-quantum
X25519 + ML-KEM-1024
Optional recovery key is a hybrid post-quantum wrap (FIPS 203), so a quantum future can't break it.
Passphrase policy
Enforced
Length, entropy and blocklist checks — the same bar in the browser and the CLI, from shared Rust code.
No cloud, no telemetry
Local-only
Crypto runs on your device. Nothing is uploaded; the browser vault works fully offline on file://.
Secret hygiene
Zeroize + mlock
Master secrets and keys are mlocked and zeroized on drop; clipboard auto-clears after 30 seconds.
