Your passwords, TOTP codes, SSH keys, and notes live in a single encrypted file on a USB drive — opened entirely in the browser. No account, no cloud, no app to install on the machine you use it on. Nothing decrypts without your passphrase.

Install

Run this once to install the fob command (used only for installing/updating and USB operations). Daily use happens in the browser — open index.html on the USB.

curl -fsSL https://raw.githubusercontent.com/Arcel-Org/Fob/main/install/install.sh | sh

SHA256 of install.sh: …

The command above is pinned to the latest release tag, so what you run today is exactly what shipped with that release. The hash is fetched live so you can verify before piping to a shell.

Check your version

  • fob status — lists detected USB drives, shows whether each has a vault, and prints the installed Fob version.
  • fob update --check — compares your installed version against the latest release.
  • On the USB — open a vault file and click Vault info in the browser to see its format version, KDF (Argon2id), and fingerprint.
